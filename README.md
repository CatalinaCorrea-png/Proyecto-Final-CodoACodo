
# Página web de películas — Front-end

Sitio de películas hecho con HTML, CSS y JavaScript puro. Consume la API de
[TMDB](https://www.themoviedb.org/) para mostrar las películas mejor puntuadas.

Proyecto del curso **Codo a Codo** (2024).

## Qué incluye

- Home con buscador, sección de tendencias y "Las más aclamadas", esta última
  cargada desde la API
- Página de detalle de película
- Formularios de registro e inicio de sesión con validación en JavaScript
- Diseño responsive con Bootstrap 5 y animaciones AOS

## Estructura

```
├── index.html
├── estilos.css
├── css/      # estilos por sección
├── js/       # index.js (API), validar.js (formularios)
├── img/
└── pages/    # detalle, registrarse, sesion
```

## Cómo verlo

Abrir `index.html` en el navegador. No necesita instalación ni servidor.
